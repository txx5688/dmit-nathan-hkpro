# DMIT Nathan：弥敦道限量套餐还能不能买到，抢不到的话香港 Pro 该怎么选

先给结论，省得你翻半天。

DMIT Nathan（完整名字 HKG.Pro.Nathan）是 DMIT 香港 Premium 线路上的一款限量套餐，年付 $178.80，1 核 1G、20G SSD、450GB 月流量。它属于已经下架不再补货的那一批限量机型，现在官网买不到，想找"同款现货"基本没有官方渠道。

所以真正值得聊的是两件事：Nathan 当初为什么被叫作"传家宝"，以及现在想上香港 Pro 这条线，还有哪些在售选项、各自贵在哪。

## 这个名字从哪来的

DMIT 的香港 Premium 限量系列有个习惯：拿香港本地地名当机型名。旺角对应 MongKok，弥敦道对应 Nathan，还有维多利亚（Victoria）和落马洲（Lokmachau）。公开整理的名单里偶尔还能看到荃湾（TsuenWan），不过多数汇总只列四款限量。

Nathan 就是弥敦道——不是人名，是九龙那条主路。知道这一点之后，你会更容易理解这批机器的定位：香港本地节点，卖点不在配置，在回程线路。

## 线路才是它贵得有理由的部分

香港 Pro 的回程走法大致是这样：三网回程经香港 CTG 接入电信 CN2 GIA；电信去程走 CN2 GIA 直连香港 CTG；联通去程经 AS4837 / AS10099 进香港；移动去程走 CMI。

翻译成人话——电信用户去程回程都在 CN2 GIA 上，联通走的是直连香港的 4837，移动走 CMI。没有绕路，没有公网拥堵段。

拿延迟对比一下就很清楚：洛杉矶的 Pro 系列对大陆方向即使走 CN2 GIA，正常也要 150–180ms；香港节点通常在几十毫秒级别。同样一条"优化线路"的标签，香港和洛杉矶的实际体感差一大截，这就是香港 Pro 长期缺货的原因。

## 那次全线流量升级，Nathan 从 300GB 变成 450GB

DMIT 在端午节期间通过官方社群发布过一次 HKG Pro 的流量升级公告：覆盖 4 款限量套餐和 7 款常规套餐，共 11 款，老用户不需要任何操作，系统自动生效，新下单也直接按升级后的额度走。

限量套餐的调整幅度：

- HKG.Pro.MongKok：200GB → 300GB
- HKG.Pro.Nathan：300GB → 450GB
- HKG.Pro.Victoria：500GB → 800GB
- HKG.Pro.Lokmachau：600GB → 1000GB

常规套餐那一侧同样有调整，比如 TINY 从 400GB 提到 500GB，GIANT 从 3000GB 提到 6000GB，直接翻倍。

这件事的意义在于：那批已经售罄的限量套餐，老用户手里的实际额度也一并涨了。所以你现在如果在二手渠道看到有人描述"Nathan 450GB"，那不是改配，是官方的正常升级。

## $178.80 一年，便宜在哪，代价是什么

算一下就知道为什么当年抢得凶：$178.80 摊到 12 个月，大约每月 $14.9。

而现在在售的 HKG.Pro.TINY，月付标价 $39.90，流量 500GB。也就是说 Nathan 用不到常规款四成的月单价，拿到了接近的流量。

代价有两个，得说清楚：

端口只有 300Mbps，常规 Pro 是 1Gbps。流量 450GB，比 TINY 的 500GB 少一点点。放在建站、API 转发、小规模代理这些场景里，300Mbps 通常不是瓶颈；但如果你要跑大文件分发或者高并发下载，这个端口会成为限制。

换句话说，Nathan 是"低价换小口"的产物，不是无脑更强的机器。

## 下单前后容易踩的坑

注册环节：填真实信息，把代理工具关掉。DMIT 有风控，明显异常的 IP 或伪造信息可能直接触发退款。

登录方式：默认走 SSH 密钥，不是密码。第一次连之前要先在面板里上传或生成公钥，不熟这一步的人建议先看官方知识库，别等买完了卡在登录上。

付款：支持支付宝、PayPal、信用卡，支付宝到账最快。

退款：规则是可以查的——购买 3 天内且流量使用不超过 30GB，可申请全额退款（要扣支付网关手续费）；30 天内可以按剩余服务时长比例退部分款。续费订单和用余额支付的订单不在退款范围内。

IP 被墙：可以申请更换，被确认封禁的情况下每 15 天免费换一次，其他情况 $5 一次。需要通过工单申请并给出确认依据。

另外说一句，公开测评普遍提到 DMIT 不超售、线路稳定，也提到它是搬瓦工 CN2 GIA 线路的上游供应商之一。这两条能解释它为什么贵，但都不构成"你必须买"的理由。

## 常见问题

**Nathan 会补货吗？**

按目前公开的信息，官方没有对这四款限量套餐宣布任何补货计划，它们在产品页上的状态就是售罄。能不能等到，没有任何人能给你确定答案。

**Nathan 和 HKG.Pro.TINY 该选哪个？**

理论上这是两种预算逻辑。Nathan 年付 $178.80，折合每月约 $14.9，但端口 300Mbps、流量 450GB；TINY 月付 $39.90，端口 1Gbps、流量 500GB。如果 TINY 的年付结算价在你可接受范围内，追求端口和流量就选 TINY；如果你在意的是摊薄到每月的成本，Nathan 当年的定价确实更狠——问题是它已经买不到了。

**香港 Pro 和洛杉矶 Pro 怎么选？**

看你对延迟的敏感度。要大陆方向的低延迟、低丢包，香港优先；如果只是建站、外贸或者对延迟没那么较真，洛杉矶 Pro 的入门款月付门槛更低，预算能省不少。

**流量用完了会停吗？**

这一点要分清产品线。Tier 1 系列超量后是降速不停机，降到 50Mbps 到 1Gbps 不等，具体看套餐。Pro 系列的规则不一样，下单前请以官网产品页写明的条款为准，别拿 T1 的行为去套 Pro。
